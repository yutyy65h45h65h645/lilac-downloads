# Lilac Client

[Download the latest Lilac jar](https://github.com/yutyy65h45h65h645/lilac-downloads/releases/latest)

Minecraft Java 1.21.11 with Fabric Loader 0.19.0 or newer, Fabric API and Java 21 or newer.

## Automatic updates

Use the updater-enabled jar once. Lilac checks this release page in the background, verifies the download and installs it after you close Minecraft. The previous jar is backed up. Open **Right Shift > Settings > Updates** for status, **Check now**, or the automatic-update switch.

Future releases are delivered through the latest release's `latest.json` asset. This repository contains public downloads and their update feed.

## Included features

Client-side world TV and browser remote, smoothly typed lyrics, selectable fonts, customizable HUD and glass menus.
